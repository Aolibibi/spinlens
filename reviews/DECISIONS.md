## 1. 我自己的实测：规格承诺的准确率不成立

拿 SPEC §6 的 T1 示例规则（原样照搬，lexiconWeight=0.25）跑真实语料 1802 条 → **命中 10 条**。逐条人工判定：

| # | 评论（节选） | 判定 |
|---|---|---|
| 1 | 典中典洗地之：别争了它自己选了 两边都有问题 | ❌ 反讽引用 |
| 2 | 警惕盾兵出来清理战场，盾兵常见话术为：1.和稀泥型…9.反饭圈型 | ❌ 引用清单 |
| 3 | 别被人当枪使一帮理中客可以歇歇了…觉得"双方都有错"也可以歇歇了 | ❌ 在骂理中客 |
| 4 | 都别吵了，老婆是我的老公也是我的 | ❌ 玩梗 |
| 5 | 都别吵了，我支持奶龙鲸[doge] | ⚠️ 玩梗式消解 |
| 6 | 都别吵了，一个是梁子，一个是鲸鱼娘 | ⚠️ 玩梗 |
| 7 | 都别争了，ds自己选的 | ✅ 真·和稀泥 |
| 8 | 你们都别争了，这个才是真正的形象 | ⚠️ 玩梗 |
| 9 | 这下又成两边都有错了哈哈哈哈哈哈 | ❌ 讽刺 |
| 10 | …在各个评论区发"我都可／双方都有错／都好呀"…没有任何好处 | ❌ 在批评这种发言 |

**精确率 ≈ 10%（严格）～ 40%（宽松）。SPEC §14-M2 的「准确率 ≥80%」是拍脑袋写的，必须撤销并重定。**

**副产物（对视频叙事有直接价值）**：第 2 条是有人在评论区**原样手打了那 9 类清单**，还配了句「警惕盾兵出来清理战场」。→ 本工具的叙事应从「我发明了一个思路」改为「**我在把一件已经发生的事自动化**」。

## 3. 我的处方（对应审查建议，含 1 条部分驳回）

| # | 改动 | 来源 | 代价 |
|---|---|---|---|
| 1 | L3 改**逐次命中降权**（不再整条连坐）+ **两段式闸门**（pattern 闸门 AND 总分阈值） | 规则引擎 F-02/F-03 | ~30 行 |
| 2 | 删「不就是」+ 建 18 条原型回归夹具 → `--selftest` | 规则引擎 | 删一个词 + 夹具 |
| 3 | `fetchComments(target,opts) → Comment[]` 改为 **→ FetchResult**（含 allCount/errorCount/elapsedMs/truncated）；加**可重入**约束，禁止模块级可变状态（否则批量模式第 3 个视频会显示三次累计的 errorCount） | 耦合 BLOCKER-2 | 改返回类型 |
| 4 | 注入 `now` / `sleep`（否则 WBI 黄金测试写不出来，而 WBI 变更被标为"致命"风险；且单测要空等 7.3s） | 耦合 | 2 个参数 |
| 5 | 正则安全三件套：强制剥 `g/y` 标志、加载期静态 lint、匹配前归一化+截断（`(a+)+$` 会编译通过并卡死主线程） | 规则引擎 F-05/F-06 | ~20 行 |
| 6 | Reporter 拆成 `renderSummary(model)` / `renderCsv(model)`（原 `report(result,format)` 是排他选择器，与"摘要+CSV 同一次都要"冲突）；补 `Comment[]→Reporter`、`RuleSet→Reporter` 两条缺边 | 耦合 | 接口重写 |
| 7 | **新增 Refiner 模块**（`aiImpl` 注入，与 `fetchImpl` 对称）——主人要 AI 能力，不能砍 | 耦合 | 1 个模块 |
| 8 | **小红书**：保留最小桩 + 契约注释 | 耦合建议砍掉 → **部分驳回** | 1 个文件 |

> **驳回理由**：审查员判定它是"假 seam"（桩抛异常 + CLI 无 `--platform` = 不可达死代码），技术上正确。但主人明确要求「小红书留接口」，故保留最小桩，并在文档里**诚实标注"预留位，非真 seam"**，不假装可扩展。

## 4. 可行性审查的高价值 MAJOR（全部接受）

| ID | 问题 | 动作 |
|---|---|---|
| M-2 | **没有"抓不到时的兜底"**：接口一变，工具什么都不产出，"抛砖引玉"变翻车现场 | 加 `--from-json` / `--demo`（本期 1802 条样本随仓库走）。**审查员最推荐加的一条，我同意** |
| M-8 | **CSV 公式注入**：实测 25/1802 条以 `= + - @` 开头（1.4%），且 evidence 因 `{0,8}` 必然含逗号 | 全字段转义 + 危险前缀加 `'` |
| M-9 | 证据区间失真：164/1802 含换行、114/1802 含 emoji（代理对会被 slice 切断） | 归一化必须**等长**替换；证据直接取 `match[0]` |
| M-10 | 10 万条评论实测 **7176 字节/条** → 原样累积 ≈ 684MB | 每页立即映射；`--max-comments` 默认改 **2000** |
| M-11 | **合规**：CSV 带真人昵称 + 批量能力 = 天然的挂人名单 | 加 `--anon`；README 红线；**不提供批量循环参数**；免责声明也写进 CSV |
| M-12 | **不支持 b23.tv 短链** —— App 分享格式是【标题】+ https://b23.tv/xxx，**录视频第一个动作就会翻车** | 支持 b23.tv 与整段分享文本解析 |
| M-6 | Windows `>` 重定向写出 **UTF-16LE**，废掉 BOM 承诺 | README 禁用重定向（走默认 `--out` 自写文件） |
| M-7 | **Node 全局 fetch 完全忽略 HTTP(S)_PROXY** | 展开 `err.cause.code`；README 写明不支持代理 |
| M-3 | Referer 填错 → HTTP 403 + 空 body → `res.json()` 抛异常 | **先判 res.ok/content-type，禁止直接 .json()** |
| M-13/14 | 验收不可度量（30 条样本 CI = ±14pt） | 随机抽 200 条 → `golden-*.csv` → `eval.js` 混淆矩阵；**precision ≥ 0.8**，recall 只记录 |
| 其他 | M-4 错误码表 / M-5 Node ≥20.19 / M-15 nav 异常 / M-16 AI 降级要显示不要静默 | 照单接受 |

**额外两条（近乎零成本）**：
- 实测 **100% 评论带 `content.jump_url`** → 加进 Comment 模型。「结合原文人工复核」从一句话变成一个可点击链接，**直接强化主人要求的第 3 条免责声明**。
- 实测 **604/1802 主评论已内联 1-2 条楼中楼** → §1.2 必须明说"明确丢弃"。

**审查员未能验证（诚实标注）**：海外/港澳台 IP 免登录能否拿全量——本机 curl 在沙箱不通，无数据。建议发视频前用海外 VPS 跑同一段探针，否则 README 写"请在境内网络使用"。

## 5. 已核对无误（不必改）

- wts 时钟偏移**不是风险**：now±30s/±1h/±24h 全部 code=0
- 游标跨进程可复用；61 页 rpid **零重复**；ps 上限确为 30
- 「默认不带 cookie」硬性正确（带半套 → 3 条）
- `Comment[]` 切断 Fetcher↔Detector 方向正确；Detector 纯函数正确
- §4.3「明确不引入的 seam 清单」被两份审查同时评为全文最有价值的一段
- 全篇没有一条建议要求加新架构（除 Refiner，且那是主人明确要的 AI 能力）

## 7. 结论

规格的**基本盘是好的**——没有任何一条审查要求加新架构；两个耦合 BLOCKER 的修法是"改一个返回类型"和"加 3 行自检"。
真正的两个问题是：
1. **有几处没做完**（职责落进 CLI、9 类没定义、FetchResult 缺位）
2. **准确率承诺没有实测支撑**（§1 实测 10–40%），需要一轮拿 1802 条做开发集的规则调优迭代

修订 SPEC → 复审 → 才谈实施计划。**代码仍然一行没写。**
