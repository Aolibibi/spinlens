# spinlens · 话术照妖镜

> **誓死捍卫大肥鱼 o7**

**这是什么**：给它一个 B 站视频，它会扫这个视频的评论区，告诉你哪几条评论在用话术、分别属于哪一类、原话是哪一句。

**它是筛子，不是判决。** 它只回答「哪条评论命中了哪一类话术」，不回答「谁在使坏」。

---

## 缘起

2026 年 9 月，B 站上围绕 DeepSeek 拟人形象（「男设」vs「鲸鱼娘 / 大肥鱼」）爆发了一场大规模争论。

翻评论区时我们注意到一个现象：**大量发言不是「观点」，而是「话术」**——和稀泥、假中立、扣帽、拿元概念定性。这些话术不生产信息，却会让讨论越吵越糊：你反驳的是内容，对方回应的是姿态；你想把一件事说清楚，最后变成互相定性。

**这个项目要做的不是帮谁赢，而是把这些手法照出来**——这就是中文名叫「照妖镜」的原因。

> 声明：本项目不对该事件中任何一方作对错评判，不评价谁对谁错，也不点名针对任何真实个人。它标注的是**语言现象**，不是**人的罪状**。

---

## 它能识别什么

粘一个 B 站视频链接或 BV 号，它会扫描该视频的评论区，标出命中话术的评论，并给出逐字证据原话和 8 类标签。

| 编号 | 名称 | 一句话 |
|---|---|---|
| **T1** | 和稀泥 | 「都别吵了」「各有各的道理」——把是非问题搅成态度问题 |
| **T2** | 假中立 | 摆出中立的姿态，实际把举证责任单方面压给一方 |
| **T3** | 消解·梗 | 用玩梗把严肃议题变成段子，讨论从此不可继续 |
| **T4** | 消解·轻描淡写 | 「多大点事」「上纲上线了吧」——把具体伤害降级成情绪 |
| **T5** | 扣帽·软色情 | 用性暗示给人贴标签，绕开论证直接贬值对方 |
| **T6** | 扣帽·性别 | 把议题归因到性别身份，用阵营替代论证 |
| **T7** | 信息茧房 | 「你们那个圈子就那样」——用来源否定内容 |
| **T9** | 反饭圈 | 以「反饭圈」之名行扣帽之实，姿态正确、论证为零 |

**T8（胜利后劝和）已经砍掉，不训练、也不在页面上显示。** 原因是：在本事件的语料里这种话术几乎不存在——全部语料里只有 **2 条**，而且人工复核判定两条都是误标。留一个没有正例的类别，只会让模型多一个随机输出的口子，所以直接砍掉。模型和页面都只用上面这 8 类。

每条命中都会带**逐字证据原话**（抄回原文的那句话）。你可以点开原文逐条核对。

想看这 8 类具体长什么样（8 条正例 + 4 条反例，每条都带实测概率），见 **[docs/EXAMPLES.md](docs/EXAMPLES.md)**。

## 怎么装、怎么跑

### 先知道一件事：模型权重不在这个仓库里

权重约 **390 MB**，超过 GitHub 单个文件 100 MiB 的上限，塞不进 git，所以单独挂在 Release 上。

- 想用「本地微调模型」这个引擎，**必须额外做一步安装**（下面第 2 步）。
- **不想下也行**：另外两个引擎（LLM 模式、决策模型模式）**完全不需要权重**，clone 下来就能用。

前置条件：**Node.js ≥ 20.19**（内置 `fetch` 需要）。**不需要 npm 依赖，不用 `npm install`。**

### 一键安装（推荐）

**Windows**（在 PowerShell 里粘这一行，会在当前目录建一个 `spinlens` 文件夹）：

```powershell
git clone https://github.com/Aolibibi/spinlens.git; cd spinlens; powershell -ExecutionPolicy Bypass -File .\install.ps1
```

**macOS / Linux**：

```bash
git clone https://github.com/Aolibibi/spinlens.git && cd spinlens && ./install.sh
```

这两个脚本做两件事，都在仓库里，可以直接打开看：

1. 把权重下载到 `./model/` 文件夹（启动器会自动认这个文件夹，不用配任何环境变量）
2. 找一台装了 `torch` 和 `transformers` 的 Python，把它的路径写进 `./python-path.txt`

找不到合适的 Python 不会报错退出——它会告诉你怎么补，并明确告诉你「本地模型引擎用不了，但另外两个引擎照常」。下载失败也一样，不会卡住。

### 手动安装（不想跑脚本）

```bash
git clone https://github.com/Aolibibi/spinlens.git
cd spinlens
mkdir model          # 去下面「下载模型」一节，把 8 个文件下到 ./model/
node server.js
```

然后浏览器打开 **<http://127.0.0.1:8787>**，粘一个 B 站视频链接或 BV 号，点「开始扫描」。

服务只监听 `127.0.0.1`，别人访问不到，**不上传任何数据**。

### 启动

**Windows**：双击 **`启动.cmd`**。它会开一个黑窗口、自动拉起模型和网页服务、并打开浏览器。**关掉这个黑窗口，服务就停、显存释放。**

**macOS / Linux**：自带的 `启动.cmd` 是 Windows 批处理文件，用不了。请开两个终端：

```bash
python3 model-server/serve.py --port 8790 --model model   # 终端 A：模型服务（没下权重就跳过）
node server.js                                            # 终端 B：网页服务
```

> 核心库文件名 `huashu.js`、`server.js` 是**历史遗留**（项目曾用名 huashu-lens / 话术透镜）。
> 改名要牵动一整条 `require` / 启动脚本 / 文档引用链，风险大于收益，所以文件名保留不动，只改产品名。

## 三种引擎的区别

在网页右上角的引擎卡片里切换，默认是「本地微调模型」。**这三种引擎显示出来的东西是刻意做得不一样的**——它们不是同一份结果的三种皮肤：

| 引擎 | 显示形式 | 前置条件 | 成本 / 速度 |
|---|---|---|---|
| **本地微调模型**（默认） | **8 类概率条** + 阈值滑块高亮 | Python 3.10+、`torch` + `transformers`、**自备权重**（约 390MB，不随仓库发布 → 见下面「下载模型」） | 完全离线；单条约 **40ms**；占约 1GB 显存 |
| **LLM 模式** | **类型徽章 + LLM 文字理由 + 逐字证据原话**（正文里把那句原话高亮）——**不出概率条** | 任意 OpenAI 兼容接口（baseUrl + apiKey + 模型名） | 按 API token 计费；评论会发到**你自己填的那个接口**；没有概率，只有「像不像」 |
| **决策模型模式** | **8 类概率条**（与本地模型一致），阈值滑块可调 | Jev / TypeSafe System One 的 key（默认端点 `https://api.typesafe.ai`，路径 `/v1/systemone`） | 按请求计费；官方**没有批量接口**，所以请求数约等于评论数 |

三种引擎读的东西不一样：

- **本地微调模型**：读每个类别独立的 `P(正例)`，要不要算命中由阈值滑块决定。它**给的是概率条**。
- **LLM 模式**：读大模型自己的自然语言判断。**判定必须能把证据逐字抄回原文，抄不回去的一律丢弃**（这就是「逐字证据原话」的意义）。它不显示概率，因为大模型给的数字不是校准过的概率。
- **决策模型模式**：读官方返回的 **`P(true)` 校准概率**（`answers.<类型id>.noul`），**不读 `top_probability`**——后者是「获胜选项」的概率，不是 P(true)，拿它当 P(true) 会把每一类都判成命中。显示形式和本地模型一致。

### 本地模型引擎怎么找 Python

找不到也完全不影响另外两种引擎。启动器按这个顺序试，**第一个能跑 `import torch, transformers` 的胜出**：

1. `HUASHU_PY` 环境变量
2. `python-path.txt`（项目根目录，一行路径；`install.ps1` / `install.sh` 会自动写）
3. 项目内 / 项目同级的 `python_embeded/`
4. `.venv/`
5. PATH 上的 `python` / `python3` / `py -3`

> **为什么用文件而不是让用户设环境变量**：Windows 上 `setx` 只写注册表，
> 而**已经在运行的 `explorer.exe` 不会刷新环境变量**——从资源管理器双击 `启动.cmd` 时
> 子进程继承的是旧环境，`HUASHU_PY` 根本读不到。文件没有这个问题，双击就生效。

**权重目录**默认就找项目里的 `./model/`。要换位置，用 `HUASHU_MODEL` 指到那个目录即可。

```bash
python3 -m pip install torch transformers    # 缺依赖就装这个
```

## 下载模型

**spinlens 中文话术识别 v1.0**：Erlangshen-Roberta-110M 微调，8 类多标签，约 390 MB（fp32）。

**下到哪里**：项目根目录的 **`./model/`** —— 启动器会自动认它，不用配任何环境变量。

```bash
mkdir -p model && cd model
BASE=https://github.com/Aolibibi/spinlens/releases/download/0.0.1-bigfisho7
for f in config.json tokenizer.json tokenizer_config.json model.safetensors \
         README.md LABELS.md apply_info.json LICENSE; do
  curl -fLO "$BASE/$f"
done
```

Windows 一行版（PowerShell）：

```powershell
mkdir model -Force | Out-Null; $b='https://github.com/Aolibibi/spinlens/releases/download/0.0.1-bigfisho7'; foreach($f in 'config.json','tokenizer.json','tokenizer_config.json','model.safetensors','README.md','LABELS.md','apply_info.json','LICENSE'){ curl.exe -fL -o "model/$f" "$b/$f" }
```

权重发布在哪、8 个文件分别是什么、万一要重发怎么办，见 **[docs/PUBLISH-MODEL.md](docs/PUBLISH-MODEL.md)**。

## 这个模型是怎么训出来的

### 为什么要自己训一个模型

- **项目初期基于关键词的思路被否**：纯关键词太废物了，在正反方都用一样的词汇时，基于关键词识别基本失效
- **基于LLM的判断过慢**：LLM为200条打标大概需要15分钟，基本不可用
- **市面上的决策模型没有训练**：但是可用，所以还得训练下
- 结论：**本地决策模型牛逼**——用大模型的「判断能力」去批量造标签，用小编码器的「成本」去把判断变成离线、免费、可复现的能力。

### 数据

- 自采 B 站评论 **19,903 条 / 97 个视频**。
- **语料不随仓库发布**（隐私与合规）：涉及真实用户发言，进不了公开仓库。

### 打标

- 用 DeepSeek 按最初那套 T1–T9 定义逐条判定，共标 **3785 条**（去重后）。标的过程中发现 **T8（胜利后劝和）符合的只有 2 条**，打了也没意义，所以最后只按 **8 类**训练。
- 要求模型**逐字引用证据**，并做**机械校验**：证据在原文里找不到就整条丢弃。


### 训练配置

- 基座：**Erlangshen-Roberta-110M**
- 任务：**8 类多标签**（8 个独立二分类头，不是 9 分类 softmax）
- 损失函数：**BCEWithLogitsLoss**
- 处理不均衡：**`pos_weight = sqrt(neg/pos)`**。不用 `neg/pos`，因为那样稀有类会得到几百上千的权重，梯度被它彻底支配，模型对稀有类一律输出接近 1，精确率直接归零。
- `max_len 256`、`batch 32`、`lr 3e-5`、**全参数解冻**、`20 epochs`、`seed 42`
- **防泄漏**：把用于验收的 **200 条人工标注的 rpid 从训练集里彻底剔除**——否则等于拿考卷当课本。

### 三次失败换来的三条经验

这三条都是真金白银烧出来的，写出来是为了让你少烧一遍：

1. **冻结编码器、只训分类头** → 可训练参数只有 **0.01%**（6921 个），5 轮后退化成**「全判负」**：它学会了对所有输入都说「不是」，因为在正例率只有个位数的数据上，这是最快降低 loss 的路。
2. **只解冻最后 2 层**（**14.4%** 参数）→ 输出接近常数，**教科书样本都不亮**。此时那个 **「18.8% 精确率」是噪声撞出来的假象**——不是模型学会了，是评测集太小，随便蒙都能蒙出这个数。
3. **全解冻 + 20 轮** → 教科书样本 **8/8 全中**、正负样本区分度 **70–500 倍**。这才是真的学到了东西。

**一句话**：小模型微调里，「训多少参数」和「训多少轮」不是调优项，是**能否学到**的开关。

## 已知限制

- **只支持 B 站**（bilibili.com）。没有微博 / 知乎 / 小红书。
- **模型输出不一定准确**，见上面「准确率」一节。
- **语料不随仓库发布**：训练语料、人工标注、模型权重都在开发者的 `lab/` 下，已在 `.gitignore` 排除。
- **人工标注者之间一致性极低**（三方 α = −0.036），所以**绝对准确率无法宣称**。
- **不抓楼中楼**（只抓主评论），但摘要里会同时显示「总评论数」，不会让你以为抓漏了。
- **不判断立场、不判断真假**，只标「这段话像不像某类话术」。
- 触发 B 站风控时会拒绝出报告（故意的，避免「平静地打出一份错报告」）。
