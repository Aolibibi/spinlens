话术照妖镜 · 评论区话术扫描

粘贴一个 B 站视频链接或 BV 号，扫描评论区里有多少条评论在使用话术、分别是哪几类、原文是哪条。它是筛子，不是判决。
本地微调模型 推荐
我们自己微调的 Erlangshen-110M（8 类多标签、约 40ms/条、完全离线）。教科书样本 8/8 全中、区分度 70–500 倍；真实评论上的准确率没做过严格人工统计，作者体感约 70%——当粗筛用，必须人工复核。
⚠ 需先启动本地模型服务：model-server/serve.py（127.0.0.1:8790）
判定阈值 0.60
外部模型引擎
支持两种接法，两者的显示方式完全不同：
把九类规则写成提示词发给你的 LLM，让它逐条判断「作者本人是否正在做某一类动作」。显示形式：每个命中旁边标出 LLM 的文字理由 + 它从原文抄回来的证据原话，正文里把那句原话高亮；不出概率条；抄不回原文的一律丢弃。不做流式传输，但有进度条。
把每条评论当一个 state、8 个类型当 8 道 noul（是非题）塞进同一个请求（官方 fan-out），读回每道的 P(是) 校准概率（answers.<类型id>.noul）。官方无 batch 端点，所以请求数 = 评论数（而不是评论数 × 8）。显示形式：8 类概率条（与本地微调模型一致），阈值滑块可调。接口填在下面的「决策模型 API 地址」里（不是通用 LLM 接口）。⚠ 官方明确说中文准确率不背书，且不同决策模型的阈值与准确度都不一样，需要你自己微调阈值——同一套阈值换模型就会失效。
LLM 直接判定：一次把九类规则 + 一批评论发过去，要它返回「类型 + 逐字证据 + 理由」。100 条评论、每批 20 ≈ 5 次请求。
判定阈值 0.60
⚠ 这里填的是 Jev / TypeSafe System One 这类决策模型 API（不是本地 8790 那个分类服务，也不是通用 LLM 的 /chat/completions）：一次请求 = 一个 state + 多道 noul 是非题，读回 answers.<类型id>.noul（0~1 的 P(是) 校准概率）——不读 top_probability（那是「获胜选项」的概率，不是 P(true)，拿它当 P(true) 会把每一类都判成命中）。官方没有 batch 端点，所以请求数 = 评论数（8 类已合并在同一次请求里）。⚠ 官方明确说 CJK 等非英语语种「能收但不等同、先自测」，不同决策模型的阈值与准确度也都不一样，请自己微调阈值。
⚠ LLM 模式下规则匹配完全不起作用，判定口径改由提示词约束；命中必须能把证据逐字抄回原文，抄不回的一律丢弃。不同模型的结果会有差异，请把它当成「另一个标注员」，仍要人工复核。
高级设置
声明
本项目目前只支持 B 站（bilibili.com）。模型输出结果不一定准确，仅供参考，请自行人工复核。
配置需求说明（跑起来需要什么）
1）通用
· Node.js ≥ 20.19（实测 v24）；零 npm 依赖，只用 Node 标准库。
· 启动：双击根目录 启动.cmd（开一个黑窗口，自动拉起本机服务并打开浏览器）；或手动 node server.js --port 8787。
· 浏览器打开 http://127.0.0.1:8787；服务只监听本机 127.0.0.1。
2）本地微调模型 · 可选
· Python 环境：需要 Python 3.10+，且装了 torch + transformers。
· 路径怎么给：把 python.exe 的完整路径写进项目根目录的 python-path.txt（跑安装脚本会自动写）。没装 Python 不影响另外两种引擎。
· 模型权重：默认找项目根目录的 model/（Erlangshen-110M，8 类多标签）。权重不随本仓库发布，去 Release 下载后放进 model/ 即可。
· 推理服务：python model-server\serve.py --port 8790 --model model --chunk 64。
· 显存：约 1GB（实测稳态 658MiB）。
3）LLM 模式（外部大模型）
· 需要任意 OpenAI 兼容接口：baseUrl + apiKey + 模型名（例如 deepseek-chat），走 POST {baseUrl}/chat/completions。
· 不占本地显存；评论会发到你自己填的那个接口，注意隐私与 token 费用。
4）决策模型模式（Jev / TypeSafe System One）
· 默认打官方端点 POST https://api.typesafe.ai/v1/systemone（Bearer key，从 console.typesafe.ai/keys 自助取）；地址/路径留空就用这个默认值。
· 一次请求带一个 state + 8 道 type:"noul" 的是非题，读 answers.<类型id>.noul（0~1 的 P(true)）；不读 top_probability。字段名不同时在「概率字段」里手工指定。
· ⚠ 官方说明：CJK 等非英语语种「能收但不等同」，要求自己先测；不同模型的阈值也不同，请自己微调。
· 该模式的调研文档未随本仓库发布；无 batch 端点 → 请求数 ≈ 评论数。
本工具只输出「哪条评论命中了哪条规则」，不回答「谁在使坏」；请勿用它生成针对具体个人的挂人名单。
评论来自 B 站公开接口，不登录、零 Cookie；服务只监听本机 127.0.0.1，不上传任何数据。LLM / 决策模型模式下评论会发给你自己填的那个接口。
